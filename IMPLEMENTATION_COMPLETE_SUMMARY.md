## 🎨 Customization Options

### **Color Adjustments**
Edit variables in `light-theme.css` or `dark-theme.css`:
```css
.root {
    -fx-primary-color: #0A3D62;      /* Change primary blue */
    -fx-secondary-color: #FBC531;    /* Change gold accent */
    -fx-surface-color: #FFFFFF;      /* Change card backgrounds */
}
```

### **Typography Changes**
```css
.display-heading {
    -fx-font-family: "Your Font", "Fallback", sans-serif;
    -fx-font-size: 28px;
}
```

### **Component Styling**
All components use CSS classes for easy customization:
- `.stat-card` - Statistics display cards
- `.workflow-step-active` - Current workflow step
- `.priority-high` - High priority indicators
- `.quick-action-card` - Dashboard action cards
